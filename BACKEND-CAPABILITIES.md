# Backend capabilities and proof limits

The complete current operation map is [NOTEBOOK-CONTROL.md](NOTEBOOK-CONTROL.md).
It distinguishes callable tools from discovered native methods and covers folders,
notebooks, Quick sheets, pages, typed text, pictures, templates, Trash, restoration
and permanent deletion. Use that map rather than historical capability proposals.

PDF/DRM-free EPUB delivery has verified cloud metadata, original-byte tablet sync
and successful opening. New library-control wrappers add inspection, private
backups, folder creation and identity-checked move/rename. Their mutation behavior
has host proof; live account mutation qualification remains pending. Native page
editing is not exposed through those cloud tools.

Raw handwriting images can be stored in Obsidian without OCR. Four real queued
captures have verified storage receipts. The existing scheduled pass supports
local literal transcription and reviewed organization proposals; actual handwriting
accuracy is unqualified. See [RAW-VAULT.md](RAW-VAULT.md).

The tablet now uses a one-way submission workflow: Queued and History, with optional
comments. Agent answers belong in their established normal channels. Durable relay
acceptance is not proof of processing, vault organization or delivery of a response.

Cloud library sync does not require the tablet and paired server on the same Wi-Fi.
A different-Wi-Fi field test remains pending. Native maintenance SSH is reachable
only on the configured maintenance network; an authenticated awake-device relay is
still needed for native operations outside home. Never expose tablet SSH publicly.
